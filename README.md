# 🌱 Greenden

Greenden is a simple plant website created using **HTML and Tailwind CSS**.

### Pages
- 🏠 Home
- 🌿 Products
- 📩 Contact

### Features
- Responsive design
- Plant product section
- Best sellers section
- Customer reviews
- Contact form
- Simple and clean navigation

### Technologies Used
- HTML
- Tailwind CSS

### About
I created this project to practice my **HTML and Tailwind CSS** skills and to learn how to build a simple responsive website.
